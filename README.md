# 《八千萬分之1 · 江湖蒼生錄》(1 in 80 Million: Jianghu)

> 致敬話題網頁遊戲 **[《80億分之1》(1in8b.life)](https://1in8b.life/zh/)** 與 **金庸武俠世界觀** 的非營利致敬作品。

## 遊戲簡介

就在此刻，中原與塞外八千萬蒼生之間，每個呼吸都有嬰孩啼哭落地。你將成為其中一個，把僅此一次的江湖走到最後。

會降生在黃河災區的茅屋、襄陽孤城的箭樓，還是姑蘇慕容的水閣？**沒有人能選擇自己的出身**——在真實統計的江湖裡，九成以上的人終其一生都沒見過《九陰真經》。

### 核心特色
- **三大金庸紀元**：可選擇 **北宋盛世（天龍）**、**南宋烽火（射鵰·神鵰）**、**元末明初（倚天·笑傲）** 或 **任憑天命**，隨角色年齡同步觸發少室山大戰、華山論劍、襄陽城防、六大派圍攻光明頂等歷史大事件（`◆`）。
- **20 大疆域與門第加權抽選**：根據宋元明人口地理與百曉生門派分佈（91% 黎民百姓、7.5% 江湖底層、1.5% 名門世家 SSR），並提供「武林機緣加倍（俠客模式）」切換。
- **官府戶帖與江湖身契（含魚鱗冊 MRZ 碼）**：隨年齡、性別、武學境界與兵刃動態變化的像素水墨肖像與 32:10 橫幅場景。
- **四維狀態與紋銀購買力平價（PPP）**：追蹤 **體魄、心境、武學、情義** 與 **歲入紋銀（折合現代 NT$ 與白米石數）**，內建「銀兩 · 置產與修煉」系統。
- **同一時辰降生的五個人**：即時平行追蹤同辰降生於九州各處的另外四名嬰孩，並在謝世時並排對照五人最終命途。
- **駐足省思、謝世走馬燈與江湖追思祠**：在 7、16、30、50、70 歲時駐足叩問本心，命終時播放走馬燈劇場、生成《江湖命終卷宗》並支援一鍵下載分享圖卡。
